# aiTeams frontend

Next.js 15 App Router, TypeScript, Tailwind CSS and shadcn/ui.

See [the repository README](../README.md) for setup, environment variables, dev scripts and verification commands.

The Phase 0 health page calls the FastAPI backend at `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`). Adapter availability is binary discovery, not authentication/inference readiness.
